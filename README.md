# E-Commerce Data Analysis & Visualization 📊

## Overview
An exploratory data analysis (EDA) notebook built entirely on mobile using Google Colab and Python. This project analyzes customer transaction data to uncover correlations between spend amounts and gratuity trends.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Matplotlib
* **Environment:** Google Colab, GitHub Cloud Integration

## Key Insights
* **Positive Correlation:** Total bill amounts show a strong linear relationship with tip size.
* **Spend Tiers:** Identified high-value customer clusters for targeted marketing outreach.

## How to Run
Click the **Open in Colab** badge inside `Data_Analysis_Project.ipynb` to view and execute the live notebook directly in your browser.
